# Which file is which

> [!info]- The two textbooks have the same lessons
> - **Print (lessons plus Fluent in a Year):** the one to print. Black and white, with a weekly word planner after each lesson.
> - **Screen (color, lessons only):** the same lessons in color for a phone or tablet.

> [!info]- Levels and tracks
> - **Beginner:** the 26 lessons in the textbook.
> - **Fluent in a Year:** optional homework. 5 words a day takes you to all 1,500 words in 300 days. It is a pace, not a level.

> [!info]- The other files
> - **Verb Sheet:** the core verbs on one fold-out.
> - **Sentence Tiles:** print on card stock and cut out.
> - **Anki decks:** free flashcards. Year One has the class words. Fluent in a Year has all 1,500.
